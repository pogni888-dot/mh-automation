기획리뷰 시점에 테스트케이스 작성 기간/샌드박스 테스트 기간/베타 테스트 기간을 산정해야 합니다.

[대시보드 기능]


## 일정 추가
1. 제목 입력 기능
2. 날짜 입력 기능 (시작일/종료일) YYYY-MM-DD ~ YYYY-MM-DD 와 같이 시작 날짜 / 마감 날짜를 입력할 수 있어야 함. (캘린더에서 선택)
3. 라디오 버튼 제공 (검증환경 / 알파, 베타 총 2가지) 
    - 알파: 샌드박스 환경에서 테스트 진행.
    - 베타: 스테이징 환경에서 테스트 진행.
4. 설명(비고)란 텍스트 입력 기능 (해당 기능은 해당 프로젝트의 검증 특이사항이나, 검증 방법, 데이터세팅 요청 방법을 적어놓기 위함)
5. 저장 버튼을 누르면 달력 내에 해당하는 날짜에 네모 막대가 추가되고, 막대 위에 텍스트가 추가되어야함. (이건 어떻게 구현해야하지..)
6. 프로젝트 날짜가 하루가 아닌, 2일 이상인 경우 (ex: 2026-06-09 ~ 2026-06-11)
    - 해당 기간만큼 가로로 긴 네모 막대가 추가되어야함.
    - 네모 막대의 경우 해당 과제가 '알파' 인지 '베타'인지 색깔로 구분할 수 있어야 함. (알파 : 빨간색, 베타 : 파란색)
    - 만약 해당 월에서 다음 월까지 이어지는 과제일 경우 (ex: 2026-06-28 ~ 2026-07-02)
        - 6월에는 6월에 해당하는 기간만큼만 표시
        - 7월에는 7월에 해당하는 기간만큼만 표시
7. 프로젝트 이름이 길 경우, 줄바꿈하여 표시되도록 해야함.
8. 프로젝트 날짜가 서로 겹치는 경우 해당 날짜 클릭 시 우측에 해당하는 프로젝트 목록을 보여주어야함.
    - 목록 안의 프로젝트 이름 클릭 시 해당 프로젝트 일정 수정 화면이 노출되어야 함.


## 일정 수정
1. 달력 우측에 노출된 프로젝트 목록에서 프로젝트 날짜를 클릭할 경우 일정 수정 팝업이 노출됨.
2. 수정 팝업 내의 제목 / 날짜 / 비고 내용은 기존 저장된 내용이 노출되어야 함.
3. 수정 팝업 내의 닫기 버튼 클릭 시 팝업이 닫혀야 함.
4. 수정 팝업 내의 저장 버튼 클릭 시 입력한 내용이 반영되어야 함.
5. 수정 팝업 내의 삭제 버튼 클릭 시 팝업이 닫히고 해당 일정이 달력에서 삭제되어야 함.
